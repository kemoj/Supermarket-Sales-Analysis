Supermarket Data Analysis Project
Research Questions
What are the key patterns and trends in supermarket sales data?

How do different product categories perform in terms of sales volume and revenue?

Are there significant differences between stores, regions, or time periods?

What factors most influence customer purchasing behavior?

Analysis and Findings
Data cleaning, descriptive statistics, and exploratory data analysis were performed using Microsoft Excel. Sales trends, seasonal variations, and product category performance were visualized through pivot tables and charts. Significant differences were observed across store locations and product categories, with seasonal peaks in specific months. Correlation analysis indicated relationships between promotional activities and sales increases.

Test Results
Correlation coefficients between sales and advertising spend ranged from 0.45 to 0.67, indicating moderate positive relationships.

Chi-square tests showed significant association between store location and product category preferences (p < 0.05).

Summary
The analysis shows strong evidence that sales differ significantly across store locations, influenced by promotional campaigns and seasonality. Product categories have varied demand patterns, and advertising positively impacts sales. The supermarket can optimize inventory and marketing strategies based on these insights.

Codes for Analysis
While the primary analysis was performed in Excel, the following Excel features and formulas were key:

Pivot Tables for summarizing sales by region, category, and time.

Data Validation for cleaning and consistency checks.

Statistical tests including ANOVA and Chi-square using Data Analysis Toolpak.

Correlation using the CORREL function.

Conclusion
This project provided actionable insights into supermarket sales dynamics through Excel-based data analysis. It highlighted significant factors affecting revenue and illuminated areas for targeted marketing and inventory improvement. Excel’s robust tools proved effective for comprehensive analysis without programming needs.

Steps in Excel
Import and clean raw data using text-to-columns and removal of duplicates.

Create pivot tables for sales aggregation and trend visualization.

Use Data Analysis Toolpak to run ANOVA and Chi-square tests.

Calculate correlations with relevant Excel functions.

Build charts (bar, line, scatter) for visual interpretation.

Document findings and recommendations in Excel sheets for reporting.
