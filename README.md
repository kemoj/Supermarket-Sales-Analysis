# Supermarket-Sales-Analysis
This dataset and analysis help the supermarket managers identify top-performing product lines and cities.
This dataset and analysis help the supermarket:						
Identify top-performing product lines and cities.						
Evaluate customer loyalty (Member vs Normal).						
Improve marketing targeting by gender and region.						
Optimize payment channels (focus on digital payments like Ewallet).						
Track sales performance across time and categories for decision-making.
